# Midscene AGENTS

Midscene is an SDK for AI automation (browser/device agents + YAML test framework).

- Use `pnpm` only. Requires Node `^20.19.0 || ^22.12.0 || >=24.0.0`, pnpm `>=9.3.0`.
- Read `CONTRIBUTING.md` before local dev (dev servers, build wiring there).
- Before commit/PR: `pnpm run lint` from root. For code: smallest `pnpm exec nx test|build <project>`.
- Commits: Conventional Commits with required scope. See [commits & PRs](./agents/commits-prs.md).
- User-facing docs are bilingual en/zh by default. See [docs & i18n](./agents/docs-i18n.md).
